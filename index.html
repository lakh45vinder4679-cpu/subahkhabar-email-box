Setup (sirf ek baar)

Is page ko chalane ke liye aapka GitHub token chahiye. Token sirf aapke browser mein safe rehta hai (kisi server par nahi jaata).

Token kaise banayein (2 minute)
  1. Ye link kholo: github.com/settings/tokens/new
  2. Note mein likho: SubahKhabar-Email-Box
  3. Expiration: jitna chaho (jaise 90 days)
  4. Scopes mein sirf repo tick karo
  5. Generate token dabao aur ghp_... copy karo
  6. Neeche box mein paste karke Save dabao

Sirf is browser mein save hota hai. Kabhi kisi ke saath share na karo. Token revoke karne ke liye: github.com/settings/tokens

Doston ko bhejne ke liye message (copy karo)

Doston ko GitHub kholne ki zaroorat nahi. Bas ye message unhe bhej do - wo apni email bhejenge, aap yahan add kar doge, aur unhe bhi roz news aane lagegi.

Email add karo

Ek ya kai emails ek saath daal sakte ho - comma, space ya nayi line se alag karo. Jaise: ravi@gmail.com, neha@gmail.com
